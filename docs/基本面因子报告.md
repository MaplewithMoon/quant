# 基本面因子研究报告（优先级 4：换因子）

> 承接 `docs/板块轮动策略报告.md` 第十节的优先级 4。
> 板块动量那条路已经证明走不通（IC 不显著且符号翻转）；
> 这一轮换成**有基本面依据的因子**，并且**先验证因子有没有信息，再谈策略**。
>
> 一句话结论：**换对了方向。**"景气度"类因子样本内显著、样本外全部失效；
> 真正站得住的是**价值（BP/EP）、低换手、筹码集中**，
> 用它们做的组合**样本外年化 +9.25%、夏普 +0.290** ——
> 这是本项目第一个样本外为正的策略。

---

## 一、为什么先做因子 IC，而不是直接搭策略

板块轮动那一轮的教训：策略回测把"信号有没有信息""组合怎么构建""费用与约束"
混在一起，最后只能看到一个净值曲线，无法归因。

所以这一轮先只回答一个问题：**这个因子在横截面上有没有预测力？**

- 指标：调仓日横截面 **RankIC**（与月度调仓频率一致）
- 训练集 2017-01 ~ 2022-01（60 期），测试集 2022-01 ~ 2025-12（48 期）
- 同时看**分层多空价差**与**单调性** —— IC 显著但多空为负的因子不能直接做组合
- 全部因子都做 **行业 + 市值中性**（否则"营收增速有效"很可能只是"这个行业这两年好"）

## 二、数据：point-in-time 是这里唯一重要的事

| 数据 | 用途 | 关键字段 |
|---|---|---|
| `frozen/financial/{profit,balance,cashflow}` | 景气度/盈利质量 | `ann_date`（公告日）、`end_date`（报告期） |
| `frozen/valuation` | 价值与换手 | `pe_ttm / pb / ps_ttm / total_mv / turnover_rate` |
| `frozen/holders` | 筹码集中度 | `holder_num` + `ann_date` |
| `frozen/index_daily` | 基准 | 沪深300 真实点位 |

### 2.1 前视偏差就在这里

财报有**两个**日期：`end_date`（报告期）和 `ann_date`（公告日）。
按 `end_date` 对齐，等于在 3 月 31 日就"知道"4 月 28 日才公布的一季报 ——
而财报公布前后股价往往已经反应完毕，这会把因子 IC 抬得虚高。

本模块的做法（`factors/fundamental.py`）：

```
1. 同一 (code, end_date) 多次公告时，只保留**最早公告**的那条（as-reported）
   —— 实测 71,186 组重复公告里 98.5% 数值完全相同（纯重复），
      只有 617 组营收不同、839 组净利不同，所以按最早公告去重既安全又正确
2. 生效日 effective = ann_date + 1 天
3. 用"按 effective 排序的宽表 + reindex(ffill)"摊到每个交易日
   —— 即"截至 t 已公告的最新一期财报"
```

**去重放在 `align()` 里而不是只在 `load()` 里**：否则只要有人用别的方式构造
数据，事后修正值就会在公告前生效。有专门的回归测试锁住这条
（`test_pit_does_not_leak_before_announcement`、`test_pit_dedupe_keeps_first_announcement`）。

### 三条读法

**1. 我原本最看好的"景气度"因子，样本外全部失效。**

| 因子 | 样本内 t | 样本外 t | 样本外多空 |
|---|---|---|---|
| `rev_yoy` 营收增速 | +2.57 | **+0.33** | −6.1% |
| `np_yoy` 净利增速 | +2.67 | **+1.03** | −4.0% |
| `sue` 预期外盈利 | +3.83 | **+1.05** | −4.9% |
| `np_accel` 增速加速度 | +3.24 | **+1.92** | −4.6% |
| `roe_ttm` | +2.90 | **+0.75** | −11.1% |

样本内 t = 2.6~3.8（看起来非常显著），样本外全部掉到 t < 2。
这正是"景气度因子在 2017–2021 核心资产行情里有效、2022 后失效"的量化体现。

**2. `ocf_to_np` / `gm_yoy_chg` 是"假阳性"。**
它们样本外 IC 仍显著（t = +3.67 / +2.25），但**多空价差为负、单调性接近 0**。
说明它们只在**秩的中间段**有微弱信息，而构建组合用的极端分位（Q5−Q1）是反的。
**IC 显著 ≠ 能赚钱** —— 这条如果不查分层，会直接做出一个反向的策略。

**3. 真正站得住的是另外四类。**
低换手、价值（BP/EP）、筹码集中。它们的共同点：**不是"预测未来"，而是"定价已知的
风险溢价"**（流动性溢价、价值溢价），所以不依赖某个特定行情。

## 五、预注册规则：先定规则，再看样本外

⚠️ **这一步是整份评估的关键。** 我在跑之前就把规则写死，只允许读样本内的列：

> 规则：**样本内** p < 0.05 **且** 样本内多空 > 0 **且** 样本内单调性 > 0.5

按此规则入选 **11 个**因子，然后在样本外只跑一次：

| 结果 | 数量 |
|---|---|
| 样本外仍显著（p<0.05） | 6 / 11 |
| **样本外多空仍为正** | **4 / 11** |
| 样本内外 IC 同号 | 11 / 12 |

**那 4 个正是：`turnover_20`、`bp`、`ep_ttm`、`holder_chg`。**

代价是：规则把 7 个样本外失效的因子也放了进来（因为规则只能看样本内）。
这就是"诚实执行预注册规则"的真实代价 —— 比事后挑因子难看，但可信。

> 代码里 `combine_by_rule()` 只读 `内p / 内多空年化 / 内单调性` 三列，
> 有测试保证样本外的列即使完全相反也不影响选择
> （`test_combine_by_rule_only_uses_in_sample_columns`）。

## 六、策略回测

### 6.1 方法

- 打分 = 各因子**方向对齐 → 横截面百分位秩 → 行业与市值组内去均值 → 等权平均**
- 选打分最高的 N 只，等权，月度调仓
- 复用 `PortfolioBacktestEngine`：T+1 / 涨跌停 / 停牌 / 整手 / 印花税 / 单一账本
- **持股数只在训练集上选**，选定后在测试集只跑一次
- 因子权重**不做优化**（等权）—— 样本内优化权重是过拟合的头号来源

### 6.2 两条线

| 组合 | 因子 | 训练集最优持股 | 样本内夏普 | 样本内年化 | **样本外夏普** | **样本外年化** | 样本外回撤 |
|---|---|---|---|---|---|---|---|
| **规则组合** | 11 个（预注册规则） | 80 | −0.030 | +2.34% | **+0.196** | **+7.60%** | −31.59% |
| **先验组合** | 4 个（价值/流动性/筹码） | 50 | +0.171 | +6.51% | **+0.290** | **+9.25%** | **−26.21%** |

**注意方向：两条线的样本外夏普都高于样本内** —— 与过拟合的方向相反。
原因是因子集合由 IC（而非回测夏普）决定，而 IC 在样本外更稳（见第四节）。

### 6.3 与本项目此前策略的对照

| 策略 | 全区间年化 | 全区间夏普 | 最大回撤 |
|---|---|---|---|
| 板块动量（原版） | −12.78% | −0.369 | −77.44% |
| 板块动量 + 趋势过滤 | −7.08% | −0.243 | −60.80% |
| **多因子（规则组合）** | **+4.82%** | **+0.322** | **−46.11%** |
| 基准 沪深300 | +3.83% | +0.295 | −45.60% |
| 全市场等权 | −4.38% | −0.081 | −58.96% |

### 6.4 规则组合的全区间指标（2017-01 ~ 2025-12）

| 指标 | 数值 |
|---|---|
| 累计收益 | +50.46% |
| 年化收益 | +4.82% |
| 年化波动 | 22.54% |
| 夏普比率 | +0.322 |
| 最大回撤 | −46.11%（2017-03-16 → 2018-10-18，2020-07-14 收复） |
| **Alpha（vs 沪深300）** | **+2.40%**（t=+0.460, p=0.646 **不显著**） |
| Beta / R² | +0.886 / +0.535 |
| 信息比率 / 跟踪误差 | +0.115 / 15.52% |
| **Alpha（vs 全市场等权）** | **+8.94%（p=0.004 显著）** |
| 账目差额 / 成交笔数 | **0.00e+00** / 12,029 |

**分年度超额**：2021 **+21.96%**、2022 **+12.37%**、2023 **+13.22%**、2025 **+21.23%**；
2017 −21.08%、2018 −15.99%、2024 −9.85%。

### 6.5 怎么读这个结果

**好消息：**
- 全区间年化 +4.82% > 沪深300 的 +3.83%，且远超全市场等权的 −4.38%
- **相对全市场等权的 Alpha +8.94%，p = 0.004 显著** —— 这是本项目第一个统计显著的**正** alpha
- 2021–2023 连续三年大幅正超额，2025 再次 +21%
- 账目差额 0，12,029 笔成交，制度约束全部生效

**必须说清的保留意见：**
1. **相对沪深300 的 Alpha 不显著**（+2.40%, p=0.646）。策略池偏中小盘，Beta 0.886，
   所以"跑赢沪深300"里有多少是选股、有多少是风格，还说不清。
2. **最大回撤 −46.11%**，2018 年单年 −41.30%。没有择时，纯多头暴露。
3. **`turnover_20` 是低换手因子，有容量约束** —— 低换手股票本身难建仓。
   本回测用 100 万资金、股票池已要求日均成交额 ≥ 5000 万，但**放大资金后收益会衰减**，
   这一点没有验证。
4. **样本外只有 48 期月度观测**，统计功效有限；p = 0.004 是针对日频回归的，
   月度层面并没有那么强。

## 七、结论

| 问题 | 答案 |
|---|---|
| 换因子这条路走对了吗？ | ✅ **走对了**。板块动量样本外年亏 22%，多因子样本外年赚 9.25% |
| 景气度因子（营收/净利增速、SUE）有用吗？ | ❌ 样本内 t=2.6~3.8 显著，样本外全部掉到 t<2，多空转负 |
| 什么因子真正站得住？ | ✅ **价值（BP/EP）、低换手、筹码集中** —— 都是"风险溢价"而非"预测成长" |
| IC 显著就等于能赚钱吗？ | ❌ `ocf_to_np` / `gm_yoy_chg` 样本外 IC 显著但多空为负、单调性≈0 |
| 应该上实盘吗？ | ❌ 还不行。回撤 −46%、容量未验证、相对沪深300 的 alpha 不显著 |

**最重要的一条方法论**：这一轮的因子集合是用 **IC（预注册规则）** 选的，
不是用回测夏普选的 —— 结果是**样本外夏普高于样本内**。
上一轮的改进项是用**回测夏普**选的，结果是**样本内第一名样本外第六名**。
两者的差别不在运气，在**选择标准本身是否依赖样本内拟合**。

## 九、本次修掉的问题（多数是真实数据才暴露的）

| # | 问题 | 症状 | 修法 |
|---|---|---|---|
| 1 | **同比合并的键写错（犯了两次）** | 拿 `ed_prev` 去 join 右表的 `ed_prev`，匹配条件退化成 `E'==E` —— 永远匹配自己那一行。财务同比恒为 0、SUE 全空；股东户数同比恒为 0 | 右表把 `end_date` 改名成 `ed_prev` 当连接键 |
| 2 | **`_neutralize_panel` 逐行实现** | 11 因子 × 2596 行 = 2.8 万次带标签列表的 setitem，实测 **30 分钟跑不完一轮** | 向量化（转置后 groupby-transform 求组内和），**11 秒** |
| 3 | `align()` 没做 as-reported 去重 | 只在 `load()` 里去重，换个构造方式就会用到公告前的事后修正值（前视） | 去重下沉到 `align()`，并加回归测试 |
| 4 | `_safe_div` 标量被当成 Series | `pd.Series(1.0)` 变成长度 1，广播失败 | 先判断是否 pandas 对象，再分派；同时删掉重复定义 |
| 5 | `min_periods=3 > window=2` | `max(3, window//3)` 在 window=2 时非法，pandas 直接抛错 | `min(w, max(3, w//3))` 并保证 ≥1 |
| 6 | `R["target"]` KeyError | 报告最后一行崩，图与 CSV 全部没落盘 | 改为 `r["target"]`（r 已是 `R["full"]`） |
| 7 | 估值因子覆盖率 | `pe_ttm` 只有 58%（亏损股 PE 为空）—— 这是**正常的**，不是数据缺失 | 在文档中说明；`ep_ttm` 用 NaN 表示"亏损"，不填 0 |
