# 量化系统架构图

## 总架构（分层数据流）

```
┌─────────────────────────────────────────────────────────────────┐
│                          数据获取层                              │
│  tushare (主) ─ akshare/baostock (备)                           │
│  download_tushare_raw.py / download_frozen_tushare.py           │
│  daily_update.py (每日收盘后增量更新)                             │
└──────────────────────────────┬──────────────────────────────────┘
                               ↓ 限流/断点/磁盘保护
┌─────────────────────────────────────────────────────────────────┐
│                          frozen 层（可信原始，只读）              │
│  db/frozen/  daily_raw adjust valuation dividend suspend st     │
│             index_cons index_daily industry financial margin    │
│             holders calendar stocks etf options futures          │
│  _MANIFEST.json 记录来源/规则                                     │
└──────────────────────────────┬──────────────────────────────────┘
                               ↓ rebuild_cleaned.py / daily_update
┌─────────────────────────────────────────────────────────────────┐
│                          清洗层（可再生）                        │
│  db/daily/   原始价+量额（口径一致）  _meta.json(时间戳)           │
│  db/limit/   涨跌停价（派生）                                    │
└──────────────────────────────┬──────────────────────────────────┘
                               ↓ database/loader.py（前复权现场算）
┌─────────────────────────────────────────────────────────────────┐
│                          回测层                                  │
│  DataSet(时间轴对齐) → Strategy(标准信号) → Risk(风控链)          │
│  → Order → Execution(滑点/佣金) → Portfolio → Metrics            │
│  → lookahead(未来因子检测) → Visualizer(可视化)                   │
└─────────────────────────────────────────────────────────────────┘
```

## 模块依赖图

```
scripts/
  daily_update.py ──► database/loader.py ◄── data/dataset.py
  rebuild_cleaned.py─► database/provenance.py
  backtest.py ──────► backtest/engine.py ──► execution/broker.py
                       │                       execution/order.py
                       ├─► portfolio/portfolio.py
                       ├─► risk/manager.py
                       ├─► backtest/metrics.py
                       ├─► backtest/lookahead.py
                       └─► analytics/visualizer.py
  semiconductor_rotation.py ──► database/loader.py
  validate_data.py / clean_data.py ──► db/(DuckDB直读)

database/
  loader.py ──► (读 db/frozen 各数据集)
  downloader/ ──► tushare/akshare (写 db/frozen)

data/
  dataset.py ──► database/loader.py (from_db)
  preprocessor.py（指标注册表）
```

## 核心调用链（一次回测）

```
scripts/backtest.py
  → load_dataset()        数据从数据库取（前复权）
  → make_strategy()       注册表实例化策略
  → run_backtest()
      BacktestEngine.run()
        strategy.on_bar() → Signal(标准信号)
        risk_manager.filter() → 风控拦截
        _signal_to_order() → Order
        _execute_order() → 成交(滑点+佣金)
        _apply_fill() → 持仓变动
        portfolio.update_price() → 每日估值
  → Metrics.compute()      绩效指标
  → auto_lookahead_report() 未来因子检测
  → Visualizer.plot()      可视化
```

## 数据读写约定

| 层 | 读写 | 工具 |
|---|---|---|
| frozen | 只读（增量追加） | download_*.py |
| 清洗层 | 可重建 | rebuild_cleaned.py |
| 代码 | 全部可用 | loader.py 统一入口 |
