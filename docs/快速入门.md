# 快速入门指南

5 分钟上手本量化系统。

> 📘 **要写策略**请直接看根目录的 **[`策略开发指南.md`](../策略开发指南.md)** ——
> 那里有完整可运行示例、按"我想做什么"排列的接口速查表，以及写策略前必读的七条红线。
> 本文只讲环境与数据准备。

## 1. 环境准备

```bash
cd D:\quant
pip install -r requirements.txt        # numpy/pandas/akshare/baostock/tushare/duckdb/pyarrow
```

配置数据源 token（二选一）：
```bash
# 方式A：环境变量（推荐）
setx TUSHARE_TOKEN "你的tushare_token"   # 一次设置，永久生效

# 方式B：本地文件
# 把 token 写入 D:\quant\database\tushare_token.txt
```

## 2. 数据库（已就绪则跳过）

```bash
# 全市场日线原始价 → frozen（约2小时，断点续跑）
python scripts\download_tushare_raw.py

# 其余数据集（估值/复权/分红等）
python scripts\download_frozen_tushare.py

# 重建清洗层
python scripts\rebuild_cleaned.py --verify
```

> 如果只是试跑，数据已下载可直接进入下一步。

## 3. 跑回测

```bash
# 单策略（数据库数据，默认前复权）
python scripts\backtest.py --symbol 300750 --strategy MA

# 多策略对比
python scripts\backtest.py --symbol 300750 --compare

# 教学案例合集
python scripts\backtest_demo.py
```

可用策略：`MA` `Turtle` `MeanRev` `BBand` `MACD` `DualThrust` `RSIDiv` `Pullback` `AMA` `Grid`

## 4. 每日更新（收盘后）

```bash
python scripts\daily_update.py
```
自动：增量下载 → 重建清洗层 → 校验（失败自动回滚）。

## 5. 写自己的策略

```python
# strategy/my_strategy.py
from .base import Strategy, Signal, Action

class MyStrategy(Strategy):
    def __init__(self, param=20):
        super().__init__("MyStrategy")
        self.param = param

    def on_bar(self, data, idx):
        if idx < self.param:
            return Signal(Action.HOLD)
        if ...:
            return Signal(Action.BUY, size=1.0, reason="买入")
        elif ...:
            return Signal(Action.SELL, size=1.0, reason="卖出")
        return Signal(Action.HOLD)
```

运行：
```bash
python scripts\backtest.py --symbol 600519 --strategy MyStrategy --params '{"param":15}'
```

