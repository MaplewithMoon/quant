## 二、1.1 股票池：为什么必须用历史成分

### 问题

用"今天的沪深300 成分"回测 2023 年，等于提前知道了哪些股票**后来**会被纳入指数。
被纳入通常是因为涨得好，于是回测收益被系统性高估 —— 这就是**幸存者偏差**。

### 做法

`frozen/index_cons/` 里存的是**逐期快照**（每月一次，含 `index_code / trade_date / con_code / weight`）。
`index_member_panel()` 为每个交易日找到**不晚于该日**的最近一次快照，取那一整行。

```python
from universe import UniverseSpec, build_universe, index_weight_panel, load_index_members

spec = UniverseSpec(index_code="000300.SH",   # 历史成分，非当前成分
                    min_listed_days=60,       # 剔除次新股
                    min_amount=5e7,           # 日均成交额 ≥ 5000 万
                    exclude_st=True,
                    exclude_suspended=True,
                    top_n=0)                  # 0 = 不限
mask = build_universe(panel, spec)            # 宽表 bool，index=日期, columns=代码
```

### ⚠️ 踩过的坑（已修，有回归测试）

**不能用 `pivot + ffill`。** 早期实现把快照转成宽表后逐列前向填充，结果是
"每只股票各自记住自己上次的权重"：某只股票被调出指数后，那次快照里**没有它**（NaN），
ffill 便沿用上一次的权重，**永远不会被剔除**。

| | 沪深300 每日成分数 |
|---|---|
| 错误实现（pivot + ffill） | 从 300 **虚增到 865** |
| 正确实现（取最近快照整行） | 恒为 **300** |

验证（真实数据）：

```
[OK] 000300.SH 每日成分数恒为 300
[OK] 000905.SH 每日成分数恒为 500
[OK] 成分确实在换：5 年调出 108 只、调入 108 只（未被前向填充粘住）
[OK] 只使用 <=t 的快照：2026-05-29 成分 300 只，未混入后续新进成分
[OK] 基准权重面板归一化: 20 个交易日合计均为 1
```

> 另有一个易错点：给中证500 建掩码时必须用**它自己**的成分全集。
> 拿沪深300 的代码全集去 reindex，会把不属于沪深300 的成员全部丢掉（实测 500 → 268）。

## 三、1.3 多标的回测：单一账本 + A股制度约束

原引擎 `backtest/engine.py` 只维护一个持仓。`PortfolioBacktestEngine` 支持 N 只股票，
**复用同一套执行层**（`execution/market_rules.py`、`order.py`、`broker.py`），不复制逻辑。

### 输入 / 输出

- **输入**：目标权重面板（宽表）。**非调仓日必须为 NaN**，表示"不调仓、持仓自然漂移"，
  而不是"调成 0 仓"。`build_target_weights` 已保证这一点。
- **成交时序**：默认 `next_open` —— T 日收盘算权重 → T+1 开盘成交，**无未来函数**。

### 调仓执行顺序（重要）

1. **先卖**：按目标权重算需要减仓的部分，卖出（受 T+1 可用数量约束）。
2. **再买**：用卖出回笼的现金 + 现有现金，按目标权重的比例买入，受整手/涨跌停约束。
3. **不足则按比例缩量**：现金不够时按目标金额比例缩放，不引入杠杆、不引入隐性融资。

### 验证（真实数据 + 合成数据）

```
[OK] 多标的引擎: 账目差额 0.0e+00，99 笔成交全部整手且计费，收益 33.47%
[OK] T+1：241 笔成交中无同日同股双向交易
[OK] 持仓权重合计 ≤ 1（均值 98.71%），未使用杠杆
[OK] 费用确实被扣: 无费用 1,152,886 > 含费用 1,139,295（累计费用 3,426）
[OK] 组合层涨跌停约束生效: {'参考价已在涨停': 9}
```

- **`ledger_gap` 恒为 0**：现金 + 持仓市值 + 累计费用 = 期初资金 + 已实现盈亏，逐日核对。
- **T+1**：当日买入的股票当日不可卖（`Position.available` + `new_day()`）。
- **涨跌停封板**：`low >= limit_up` 时买不进（涨停封板），`high <= limit_down` 时卖不出。
- **整手**：全部成交数量为 100 的整数倍。
- **费用分离**：佣金 / 印花税（卖出 0.05%）/ 过户费（0.001%）分别记账，不混入换手。

## 五、1.4 业绩归因

### Brinson-Fachler 分解

对每个行业 $i$：

$$
\text{配置}_i = (w^p_i - w^b_i)(r^b_i - r^b)
\qquad
\text{选股}_i = w^b_i (r^p_i - r^b_i)
\qquad
\text{交互}_i = (w^p_i - w^b_i)(r^p_i - r^b_i)
$$

**恒等式**：$\sum_i(\text{配置}_i + \text{选股}_i + \text{交互}_i) = r^p - r^b$
—— 这条性质被单测直接断言，任何实现都必须满足：

```
[OK] Brinson 恒等式成立: 配置 -4.1888% + 选股 +3.0731% + 交互 +3.0731%
                        = +1.9573% == 超额 +1.9573%
[OK] 纯配置情形：选股效应 = 6.51e-19，配置效应 = -0.7151%
```

> 单行业持仓时"选股效应 = 0"是**正确**的，不是 bug：组合在该行业的收益率就等于
> 基准该行业收益率，$r^p_i - r^b_i = 0$。

### 因子暴露

`factor_exposure(holdings, factor_z)` 内部对因子**按日做横截面标准化**
（减均值、除标准差），分母取**全池**有效样本：

- 传原始因子（如 0..29 的名次）也能得到可解释的暴露；
- 对已标准化的因子是**幂等**的（均值 0、标准差 1 再标准化不变）；
- 标准化的分母用全池而非仅持仓，否则暴露的含义会随持仓变化而漂移。

```
[OK] 因子暴露符号正确：高分组 +1.5 / 低分组 -1.5
```

## 六、1.5 因子合成

```python
from factors.composite import composite_score, correlation_matrix

corr = correlation_matrix(panel, ["bp", "vol_60"], mask)   # 合成前查冗余
score = composite_score(panel, ["bp", "vol_60"],
                        method="icir_weight",              # equal / ic_weight / icir_weight
                        panel_mask=mask)
```

- `equal`：等权（各因子先横截面标准化，再按 `direction` 对齐方向）。
- `ic_weight`：按历史 |IC| 加权。
- `icir_weight`：按 ICIR 加权（更稳健）。
- **不传 `ic_stats_map` 时用全样本 IC —— 有前视，仅供探索**。正式回测必须传
  Walk-Forward 得到的样本内 IC 统计，或用 `optimizer/walkforward.py` 的框架。

## 八、本次在真实数据上暴露并修掉的 4 个 bug

这些 bug **全部只在真实数据上出现**，合成小样本测不出来 —— 记录在此以免重犯。

### 1. `cap_weights` 权重上限发散

削掉超额部分后，早期实现"给每只未触顶的票**加上同一个比例**"，加进去的总量
不等于削掉的总量，权重和不再为 1，迭代直接发散：

| | 0.8 / 0.1 / 0.1，上限 0.5 |
|---|---|
| 修正前 | **1,153,434**（发散） |
| 修正后 | `0.50 / 0.25 / 0.25`，合计恰为 1 |

正确做法是把未触顶的票整体放大 $(room + excess)/room$。

### 2. `correlation_matrix` 在列空间不同的因子上崩溃

不同因子的覆盖股票数不同：`bp` 依赖 `daily_basic`（5,476 只），`vol_60` 有 5,480 只。
`x.notna() & y.notna()` 按列取**并集**，缺失列被填 NaN，`bool` 掩码被提升为 `float64`，
布尔索引时报 `Cannot mask with non-boolean array containing NA / NaN values`。

修正：先对齐到公共列空间，掩码显式转 `bool`，并改用位置索引而非链式对齐。
已加回归测试 `test_correlation_matrix_different_column_sets`。

### 3. `factor_exposure` 对未标准化的因子给出恒定符号

参数名是 `factor_z`（标准化值），但调用方常直接传原始因子。传 0..29 的名次时，
暴露恒为正数，符号完全失去意义。修正为函数内部按日横截面标准化（对已标准化的输入幂等）。

### 4. `rebalance_dates` / 股票池掩码的测试自身写错

- 250 个工作日 ≈ 1 年，月度调仓应是 **12~13** 次，测试却断言 48~60 次。
- 中证500 的成分数测试用了沪深300 的代码全集做 reindex（500 → 268）。
- "首日无前收"的测试没关掉 `min_listed_days=60`，20 天样本里前 59 天全被剔除，
  两个规则混在一起测不出是哪条在起作用。

**教训**：断言失败时先判断是"代码错"还是"测试错"，但**两者都必须修**——
错误的测试和错误的代码一样有害。
