# 数据库字段说明与读取案例

数据分层：`db/frozen/`（可信原始，只读）→ `db/cleaned/<配方>/`（加工，可重建）→ 指标/因子
所有读取走 `database/loader.py` 统一入口。

> 目录结构与命名规则见 [`数据结构说明.md`](数据结构说明.md)。所有路径请用
> `database.config.dir_of()` / `parquet_glob()` 获取，不要手写 `"db/xxx"` 字符串。

---

## 1. 行情日线（核心）

### 位置
- `db/frozen/daily_raw/` — tushare 不复权原始价（可信源）
- `db/cleaned/daily_basic/` — 清洗后原始价（配方 `daily_basic`，从 frozen 派生，量额一致）

### 字段

| 字段 | 单位 | 说明 |
|---|---|---|
| `code` | — | 6位股票代码 |
| `trade_date` | — | 交易日 |
| `open` / `high` / `low` / `close` | 元 | 开/高/低/收 |
| `pre_close` | 元 | 昨收 |
| `change` | 元 | 涨跌额（=close-pre_close） |
| `pct_chg` | % | 涨跌幅 |
| `volume` | 股 | 成交量 |
| `amount` | 元 | 成交额 |

### 读取
```python
from database.loader import load_daily, load_daily_qfq

# 前复权（回测默认）
qfq = load_daily("300750", "2024-01-01", "2024-12-31", adjust="qfq")
# 不复权（真实成交价）
raw = load_daily("300750", "2024-01-01", "2024-12-31", adjust="")
# 直接读 frozen 原始
frozen = load_daily_qfq("300750", "2024-01-01", "2024-12-31")
```

## 2. 每日估值

### 位置 `db/frozen/valuation/`

| 字段 | 单位 | 说明 |
|---|---|---|
| `pe` | 倍 | 静态市盈率 |
| `pe_ttm` | 倍 | 滚动市盈率（TTM，推荐） |
| `pb` | 倍 | 市净率 |
| `ps` / `ps_ttm` | 倍 | 静态/滚动市销率 |
| `total_mv` | 万元 | 总市值 |
| `circ_mv` | 万元 | 流通市值 |
| `turnover_rate` | % | 换手率 |

### 读取
```python
from database.loader import load_valuation
v = load_valuation("000001", "2024-01-01", "2024-12-31")
# 注意：total_mv/circ_mv 单位为万元，转亿元 ÷10000
v["total_mv_yi"] = v["total_mv"] / 10000
```

## 10. 财务报表

### 位置 `db/frozen/financial/year=2005/{balance|profit|cashflow}_*code*.parquet`
三张表共约 **170+ 字段**（资产负债表为主）。

| 关键字段 | 说明 |
|---|---|
| `end_date` | 报告期（季频） |
| `report_date` | 报告日期 |
| `total_assets` | 总资产 |
| `total_liab` | 总负债 |
| `total_hldr_eqy_inc_min_int` | 股东权益(含少数) |
| `total_cur_assets` | 流动资产 |
| `money_cap` | 货币资金 |
| `inventories` | 存货 |
| `accounts_receiv` | 应收账款 |
| `fix_assets` | 固定资产 |
| `goodwill` | 商誉 |
| `total_revenue`(利润表) | 营业收入 |
| `net_profit`(利润表) | 净利润 |
| `n_income_attr_p`(利润表) | 归母净利润 |

### 读取
```python
import pandas as pd, glob
f = glob.glob("db/frozen/financial/year=2005/balance_000001.parquet")

print(bal[["report_date", "total_assets", "total_liab"]].head())
```

## 组合读取案例

### 案例A：某股票完整数据集合并
```python
from database.loader import load_daily, load_valuation, load_factor, load_suspend

code = "600519"
daily = load_daily(code, "2024-01-01", "2024-12-31", adjust="qfq")
val = load_valuation(code, "2024-01-01", "2024-12-31")
factor = load_factor(code)
sus = load_suspend(code)

# 行情+估值 合并（按交易日）
merged = daily.merge(val, on="trade_date", how="left")
print(merged[["close", "pe_ttm", "pb", "turnover_rate"]].head())
```

### 案例B：指数成分 + 行情筛选
```python
import pandas as pd
w = pd.read_parquet("db/frozen/index_cons/year=2005/000300.SH.parquet")
codes = w["con_code"].str[:6].unique()[:10]   # 沪深300前10只
for c in codes:
    d = pd.read_parquet(f"db/cleaned/daily_basic/year=2024/{c}.parquet")
    print(c, "最后收盘:", d["close"].iloc[-1])
```

### 案例C：DuckDB 跨库查询
```python
from database.query import QueryEngine
qe = QueryEngine()
df = qe.query("""
    SELECT d.code, d.trade_date, d.close, v.pe_ttm, v.total_mv
    FROM 'db/cleaned/daily_basic/year=2024/000001.parquet' d
    JOIN 'db/frozen/valuation/year=2024/000001.parquet' v
      ON d.trade_date = v.trade_date
""")
```
