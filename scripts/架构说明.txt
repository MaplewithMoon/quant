当前工程代码功能结构：

数据层
database/               — 数据基础设施（Parquet + DuckDB + frozen分层）

文件	                         功能
————————————————————————————————
config.py	         路径映射：frozen层17个数据集 + 清洗层 + 磁盘阈值
storage.py	         Parquet 按年/代码分区存储 + 断点记录
loader.py	         统一读取入口：load_daily(前复权/原始)、load_valuation、load_factor、load_suspend、mark_suspended、fill_factor_nan、industry_median_factor
query.py	         DuckDB 跨库 SQL 查询
provenance.py	 清洗层时间戳/溯源 + 数据可获得日期
token.py	         tushare token 加载
downloader/	         10个数据下载器：calendar/stocks/daily/adjust/valuation/financial/indices/meta/other + 基类 + tushare客户端
————————————————————————————————

data/                        — 回测数据适配层

文件	                         功能
————————————————————————————————
dataset.py	         DataSet 容器 + from_db()（数据库加载）+ load()（远程源）
preprocessor.py	11个技术指标 + 注册表 + add_technical_indicators
source.py	         DataSource 抽象：Local/Remote(akshare/baostock)/Mock
————————————————————————————————

文件	                              策略

modern.py	            DualThrust、网格、RSI背离、突破回踩、自适应均线
